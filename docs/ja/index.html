David Mouse は、頭の動きでカーソルを操作するヘッドマウス（head-mouse）利用者のために作られた小さなツールです。 よくある悩み——わずかな頭の揺れで自動クリックが暴発し、音楽が止まる・動画が一時停止する問題——を解決します。 ワンクリックで自動クリックを停止、必要なときに再開できます。

💛 なぜこのソフトを作ったか — David のストーリー

「最も基本的な楽しみさえ奪われたとき、生きることの重さはどこに置けばいいのだろう？」

このソフトは David のために生まれました

補装具評価の仕事を続けてきた中で、頸髄損傷（SCI C-level）を抱える曾大衛（David）さんの話は、おそらく最も深く心に残っているものの一つです。

初めて会ったとき、彼の状況はひどいものでした。交通事故による脊髄損傷で身体のコントロールを失い、日常のあらゆることを奥さんに頼るしかない生活。あの小さな部屋に閉じ込められていたのは、動けない David の体だけではありませんでした。奥さんの息の詰まるようなプレッシャーも、そこにありました。作業療法士として、私の仕事は「生命徴候を維持する」ことだけではないと分かっていました——彼に「生きている感覚」を取り戻してもらうことが本当の目標でした。

彼が世界とつながれるよう、私たちはヘッドマウスを申請しようとしました。しかし慈善団体への補助申請で、やわらかな壁にぶつかりました。車いすや電動ベッドのような「従来型」の補装具には快く手が差し伸べられるのに、「マウス」となった途端、娯楽品であって生活必需品ではないという空気が漂うのです。

この社会認識のずれは、深く刺さりました。多くの人は、重度障がい者は生きていられて、動けれさえすればいいと思っています。しかし「娯楽」と「自律」こそが、人を生かし続ける原動力であることを見落としています。David にとって、ウェブを閲覧し、動画を見て、文字を打って外の世界と会話することは、贅沢でも何でもありません——それは、自分の人生をわずかでも自分でコントロールできる、唯一の小さな窓だったのです。

幸いなことに、私たちは諦めませんでした。別の資源を見つけ、何とかヘッドマウスのハードウェアを用意することができました。しかしハードウェアが揃ったあと、今度は本当の課題がソフトウェア側で浮上しました。

最初は point-n-click というソフトを使ってもらいました。機能は充実していましたが、技術的な背景のないご家族にとって、詳細設定はあまりにも複雑でした。David の奥さんは毎日の介護だけで精いっぱいで、細かなパラメーターを自分で調整するのは無理でした。さらに悪いことに、苦労してすべての設定を整えても、制御できない自動クリックが起き続けました——David がやっと動画を再生できたと思ったら、異常なクリックで「再生・停止・再生・停止」が延々と続くのです。

期待から無力感へと変わっていく彼の目を見て、「いっそ自分たちで作ろう」という考えが生まれました。

私たちは「引き算のデザイン」を核とするソフトを開発することにし、彼の名前をとって「david-mouse」と名づけました。目標は明確——本人とご家族が直感で設定できるようにし、専門家を呼ばなくても使えること。さらに多言語対応も加えました。David だけでなく、世界のどこかにいる脊髄損傷の方々も無料でダウンロードして、デジタルな自律性を取り戻せるように、という願いを込めて。

「david-mouse」が完成すると、David の生活は本当に変わりました。今では頭の微細な動きだけでマウスを操作し、自分でウェブを巡り、楽しみを探せるようになりました。奥さんに余裕が生まれただけでなく、何より——David の目に光が戻ってきました。かつて苛立ちや鬱を抱えていた彼が少しずつ変わり、この小さなマウスが「掌握する感覚」を取り戻させてくれました。彼はより大きく、はっきり話す練習を始め、歌いたいと思うようになり、もっと多くのことを自分の力でコントロールしたいと望むようになりました。

この強い意欲に乗じて、私たちはのちに電動車いすのコントローラーも改造しました。今では David は、自信を持って一人で車いすを操り外出できます。画面上の小さなカーソルから、現実世界を自由に移動する車いすへ——「david-mouse」はシンプルなソフトウェアかもしれません。しかし David にとって、それは人生を再起動する鍵であり、私たちが世界中の脊髄損傷の方々に贈りたい、ひとつの贈り物です。

🎯 主な機能

設計の中心にあるのは一つの原則：ヘッドマウス利用者でも無理なく操作できること。 すべてのボタンは大きく、コントラストが高く、ホールド（カーソルを静止させる）で起動できます。

⏯️

ワンタッチで自動クリック停止

大きな PAUSE ボタン。YouTube を見る前にホールドして停止、見終わったら再びホールドして再開。すべての操作が物理マウスなしで完結します。

🎚️

ホールド時間の調整

0.5 秒〜3 秒の間で自由に設定できます。頭の安定度は人それぞれ、自分に合うリズムを見つけてください。

🖱️

4 つのアクションボタン

左クリック・右クリック・ダブルクリック・一時停止／再開——2.5 秒のカウントダウン付きで、カーソルを目標へ移動する時間があります。

📐

画面四隅にスナップ

ウィンドウ角の矢印で、画面の左上・右上・左下・右下にウィンドウを瞬時に移動。視界を邪魔しません。

🌐

4 言語対応 UI

繁体中文 / English / 日本語 / 한국어 をアプリ内で切り替え可能。利用者・ご家族どちらの言語にも対応します。

🚀

Windows 起動時に自動開始

一度設定すれば、PC を立ち上げるたびに自動で起動。手動で開く手間がいりません。

📖 使い方

3 ステップで完了。YouTube を見る前は、必ず先に PAUSE ボタンで自動クリックを停止してください。

1

ホールド時間を設定

スライダーでクリックが起動するまでの停止時間を選びます。まずは 1.0 秒からお試しを。頭が安定している方は短め（0.5 秒）、不安定な方は長め（2 秒以上）に。

2

YouTube を見る前に PAUSE を押す

緑色の「● 自動クリック中」ボタンにカーソルを 1 秒ほど留めると自動でクリックされ、赤い「⏸ 一時停止」表示に切り替わります。これで動画視聴中に誤クリックが発生しません。

💡 視聴後に再開する：同じ赤いボタンにもう一度カーソルを留めるだけ。一時停止中は、画面上でこのボタンだけがホールドに反応するため、視聴中に頭が動いて他の場所にカーソルが行っても誤クリックは起こりません。

3

クリックしたいときはアクションボタン

「左クリック / 右クリック / ダブル」のいずれかにカーソルを 1 秒留めると、ボタンが黄色になりカウントダウン開始 → 2.5 秒以内にカーソルを目標位置へ移動 → カウント終了で自動クリックされます。

⬇ インストールと起動

現在は GitHub からソースを取得して Python で実行する方式です。 パッケージ済み .exe インストーラは近日公開予定。

🏃 クイックスタート（推奨）

Python を事前に入れる必要はありません。install.bat が未インストールを検知すると自動でダウンロード・設定します（per-user、管理者権限不要）：

# 1. ソースを取得
git clone https://github.com/renstudiodev-TW/david-mouse
cd david-mouse

# 2. ワンクリックインストール（Python と依存関係を自動処理）
install.bat

# 3. 起動
run.bat

🛠️ 単一 .exe にパッケージ化

Python なしでも動く単一 .exe にしたい場合：

# 1. PyInstaller をインストール
pip install pyinstaller

# 2. ビルド実行
build.bat

# 3. 完成した exe は dist\ フォルダ内
dist\david-mouse.exe
