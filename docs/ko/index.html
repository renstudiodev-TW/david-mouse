David Mouse는 머리 움직임으로 커서를 조작하는 헤드 마우스(head-mouse) 사용자를 위한 작은 도구입니다. 가장 흔한 문제—머리의 작은 흔들림이 자동 클릭을 유발해 음악이 멈추고 영상이 끊기는 현상—을 해결합니다. 클릭 한 번으로 자동 클릭을 일시정지하고, 필요할 때 다시 재개할 수 있습니다.

⬇ 다운로드 📖 사용 방법

💛 왜 만들었나 — David의 이야기

「가장 기본적인 즐거움마저 빼앗긴다면, 삶의 무게는 어디에 내려놓을 수 있을까?」

이 소프트웨어는 David를 위해 만들어졌습니다

보조기구 평가 일을 해오면서, 경추 척수 손상(SCI C-level)을 가진 증대위(David) 씨의 이야기는 가장 깊이 남은 사례 중 하나입니다.

처음 만났을 때 그의 상태는 매우 좋지 않았습니다. 교통사고로 인한 척수 손상으로 신체 조절 능력을 잃었고, 일상의 모든 것을 아내에게 의존해야 했습니다. 그 작은 방에 갇혀 있는 것은 움직이지 못하는 David의 몸뿐만이 아니었습니다. 숨 한번 제대로 쉬지 못하는 아내의 압박감도 그 안에 있었습니다. 작업치료사로서, 제 일은 단순히 그가 "생명 징후를 유지"하도록 돕는 것이 아니었습니다. 그에게 '생활'하는 감각을 되찾아 주는 것이 진짜 목표였습니다.

그가 세상과 다시 연결될 수 있도록, 우리는 헤드 마우스를 지원해 달라고 자선 단체에 요청했습니다. 하지만 부드러운 벽에 부딪혔습니다. 휠체어나 전동 침대 같은 '전통적인' 보조기기에는 기꺼이 손을 내밀면서도, '마우스'라는 말이 나오자 오락거리로 보는 분위기가 형성됐습니다. 생활 필수품이 아니라는 것이었습니다.

이런 사회적 인식의 차이가 깊이 와닿았습니다. 많은 사람들은 중증 장애인이 살아있고 이동할 수 있으면 충분하다고 생각합니다. 하지만 '즐거움'과 '자율성'이야말로 사람을 살아가게 하는 원동력이라는 사실을 간과합니다. David에게 웹 서핑을 하고, 영상을 보고, 타이핑으로 외부와 소통하는 것은 사치가 아니었습니다. 그것은 그가 자신의 삶을 조금이라도 스스로 통제할 수 있는 유일한 작은 창이었습니다.

다행히 우리는 포기하지 않았습니다. 다른 경로를 찾아 결국 헤드 마우스 하드웨어를 마련했습니다. 하지만 하드웨어가 갖춰지자, 이번에는 소프트웨어에서 진짜 도전이 시작됐습니다.

처음에는 point-n-click이라는 소프트웨어를 사용했습니다. 기능은 강력하고 전면적이었지만, 기술적 배경이 없는 가족 보호자에게는 고급 설정이 너무 복잡했습니다. David의 아내는 일상 간호만으로도 이미 지쳐있었고, 층층이 쌓인 매개변수를 혼자 조정하기란 무리였습니다. 더 실망스러운 것은, 힘들게 모든 설정을 마쳐도 소프트웨어에서 제어되지 않는 자동 클릭이 계속 발생했습니다. David가 겨우 영상을 재생하면, 비정상적인 클릭으로 인해 '재생·정지·재생·정지'가 끊임없이 반복됐습니다.

그의 눈 속 기대가 무력한 좌절로 변해가는 것을 보며, "우리가 직접 만들면 어떨까?"라는 생각이 떠올랐습니다.

우리는 '빼기 디자인'을 핵심으로 하는 소프트웨어를 개발하기로 결정했고, 그의 이름을 따 "david-mouse"라고 이름 붙였습니다. 목표는 명확했습니다. 당사자와 가족이 직관적으로 설정할 수 있도록, 전문가를 기다릴 필요 없이 사용할 수 있도록 하는 것. 다국어 지원도 추가했습니다. David뿐 아니라 세계 어딘가에 있는 척수 손상 환자들도 무료로 다운로드해 디지털 자율성을 되찾을 수 있기를 바라는 마음으로.

"david-mouse"가 완성된 후 David의 삶은 진짜 바뀌었습니다. 이제 그는 미세한 머리 움직임만으로 마우스를 조작하고, 스스로 인터넷을 탐색하고 즐거움을 찾을 수 있게 되었습니다. 아내에게 숨 쉴 공간이 생겼을 뿐 아니라, 무엇보다 중요한 것은 David의 눈빛이 살아 돌아왔습니다. 예전에 짜증스럽고 우울했던 David는 서서히 사라지고, 이 작은 마우스가 그에게 '통제감'을 되돌려 주었습니다. 그는 더 크고 명확하게 말하는 연습을 시작했고, 노래를 부르고 싶어졌고, 더 많은 것을 스스로 통제하고 싶어했습니다.

이 강한 동기를 발판으로, 우리는 나중에 전동 휠체어의 컨트롤러도 개조했습니다. 이제 David는 자신감 있게 혼자 휠체어를 몰고 외출할 수 있습니다. 화면 위의 작은 커서에서, 현실 세계를 자유롭게 이동하는 휠체어까지——"david-mouse"는 단순한 소프트웨어일지 모르지만, David에게는 삶을 다시 시작하는 열쇠였습니다. 그리고 우리가 전 세계 척수 손상 환자들에게 전하고 싶은 선물이기도 합니다.

🎯 주요 기능

모든 설계는 하나의 원칙을 중심으로 합니다: 헤드 마우스 사용자도 부담 없이 조작할 수 있어야 한다. 모든 버튼은 크고, 대비가 높으며, 머무름(커서를 정지시키기)으로 작동합니다.

📖 사용 방법

3단계로 완료. YouTube를 보기 전에 반드시 먼저 PAUSE 버튼으로 자동 클릭을 정지하세요.

1

머무름 시간 설정

슬라이더로 클릭이 작동하기까지의 정지 시간을 선택하세요. 처음에는 1.0초로 시도해 보세요. 머리가 안정적이면 짧게(0.5초), 덜 안정적이면 길게(2초 이상) 설정하세요.

2

YouTube 보기 전에 PAUSE 누르기

녹색 "● 자동 클릭 중" 버튼에 커서를 약 1초 머무르면 자동으로 클릭되어 빨간 "⏸ 일시정지" 표시로 바뀝니다. 이제 영상을 끊김 없이 편안하게 시청할 수 있습니다.

💡 시청 후 재개하기: 같은 빨간 버튼에 다시 커서를 머무르기만 하면 됩니다. 일시정지 중에는 화면 위에서 이 버튼만 머무름에 반응하므로, 시청 중 머리가 움직여 커서가 다른 곳에 가도 실수로 클릭되지 않습니다.

3

클릭이 필요할 때는 액션 버튼 사용

"왼쪽 / 오른쪽 / 더블" 중 하나에 커서를 약 1초 머무르면 버튼이 노란색으로 변하며 카운트다운 시작 → 2.5초 안에 커서를 목표 위치로 이동 → 카운트 종료 시 자동으로 클릭됩니다.

⬇ 설치 및 실행

현재는 GitHub에서 소스를 받아 Python으로 실행하는 방식입니다. 패키징된 .exe 인스톨러는 곧 출시 예정입니다.

🏃 빠른 시작 (권장)

Python을 미리 설치할 필요 없습니다. install.bat이 미설치를 감지하면 자동으로 다운로드·설정합니다(per-user, 관리자 권한 불필요):

# 1. 소스 받기
git clone https://github.com/renstudiodev-TW/david-mouse
cd david-mouse

# 2. 원클릭 설치 (Python + 의존성 자동 처리)
install.bat

# 3. 실행
run.bat

🛠️ 단일 .exe로 패키징

Python 없이도 동작하는 단일 .exe가 필요하다면:

# 1. PyInstaller 설치
pip install pyinstaller

# 2. 빌드 실행
build.bat

# 3. 완성된 exe는 dist\ 폴더 안에
dist\david-mouse.exe
