David Mouse는 머리 움직임으로 커서를 조작하는 헤드 마우스(head-mouse) 사용자를 위한 작은 도구입니다. 가장 흔한 문제—머리의 작은 흔들림이 자동 클릭을 유발해 음악이 멈추고 영상이 끊기는 현상—을 해결합니다. 클릭 한 번으로 자동 클릭을 일시정지하고, 필요할 때 다시 재개할 수 있습니다.

⬇ 다운로드 📖 사용 방법

💛 왜 만들었나 — David의 이야기

⚠️ PLACEHOLDER: 이 문단은 임시 텍스트입니다. 공개 전에 David의 실제 이야기로 교체해 주세요.

이 소프트웨어는 David를 위해 만들어졌습니다

David는 헤드 마우스로 컴퓨터를 사용하는 분입니다. 그에게 YouTube로 음악을 듣고 영상을 보는 시간은 편안히 쉬며 세상과 연결될 수 있는 몇 안 되는 시간 중 하나입니다.

하지만 그가 사용하는 헤드 마우스 소프트웨어에는 "자동 클릭" 기능이 있어(커서가 일정 시간 멈추면 클릭됨), 평소엔 편리하지만 YouTube를 볼 때는 큰 문제였습니다. 머리의 미세한 흔들림으로 커서가 영상 위에 잠시 멈추면 몇 초마다 일시정지·재생이 반복되어 영상을 제대로 볼 수 없었습니다.

그의 가족(저의 친구이자 환자분이기도 합니다)이 여러 상용 소프트웨어를 시도했지만 아무것도 이 문제를 해결하지 못했습니다. 그래서 저는 전용 도구를 만들기로 했습니다—— "자동 클릭 일시정지"를 한 번에 전환할 수 있는, 헤드 마우스로도 쉽게 닿는 큰 버튼이 있는 작은 창을.

이렇게 David Mouse가 시작되었습니다. David에게 도움이 된다면 같은 어려움을 겪는 세계의 다른 분들에게도 도움이 될 것입니다.

🎯 주요 기능

모든 설계는 하나의 원칙을 중심으로 합니다: 헤드 마우스 사용자도 부담 없이 조작할 수 있어야 한다. 모든 버튼은 크고, 대비가 높으며, 머무름(커서를 정지시키기)으로 작동합니다.

⏯️

한 번에 자동 클릭 정지

커다란 PAUSE 버튼. YouTube를 보기 전에 머무르면 정지, 다 본 후 다시 머무르면 재개. 전 과정에 물리 마우스가 필요 없습니다.

🎚️

머무름 시간 조절

0.5초부터 3초까지 자유롭게 설정. 각자 머리의 안정도가 다르니, 본인에게 맞는 속도를 찾으세요.

🖱️

네 가지 액션 버튼

왼쪽 클릭・오른쪽 클릭・더블 클릭・일시정지/재개 — 각각 2.5초 카운트다운으로 커서를 목표로 이동할 시간이 있습니다.

📐

화면 네 모서리에 스냅

창 모서리의 화살표를 누르면 화면 좌상/우상/좌하/우하로 창이 즉시 이동. 시야를 가리지 않습니다.

4개 언어 UI

繁體中文 / English / 日本語 / 한국어 를 앱 안에서 전환 가능. 사용자와 가족의 언어 모두 지원합니다.

🚀

Windows 시작 시 자동 실행

한 번 설정하면 PC 부팅 시마다 자동 실행. 매번 수동으로 열 필요 없이 바로 사용하세요.

📖 사용 방법

3단계로 완료. YouTube를 보기 전에 반드시 먼저 PAUSE 버튼으로 자동 클릭을 정지하세요.

1

머무름 시간 설정

슬라이더로 클릭이 작동하기까지의 정지 시간을 선택하세요. 처음에는 1.0초로 시도해 보세요. 머리가 안정적이면 짧게(0.5초), 덜 안정적이면 길게(2초 이상) 설정하세요.

2

YouTube 보기 전에 PAUSE 누르기

녹색 "● 자동 클릭 중" 버튼에 커서를 약 1초 머무르면 자동으로 클릭되어 빨간 "⏸ 일시정지" 표시로 바뀝니다. 이제 영상을 끊김 없이 편안하게 시청할 수 있습니다.

💡 시청 후 재개하기: 같은 빨간 버튼에 다시 커서를 머무르기만 하면 됩니다. 일시정지 중에는 화면 위에서 이 버튼만 머무름에 반응하므로, 시청 중 머리가 움직여 커서가 다른 곳에 가도 실수로 클릭되지 않습니다.

3

클릭이 필요할 때는 액션 버튼 사용

"왼쪽 / 오른쪽 / 더블" 중 하나에 커서를 약 1초 머무르면 버튼이 노란색으로 변하며 카운트다운 시작 → 2.5초 안에 커서를 목표 위치로 이동 → 카운트 종료 시 자동으로 클릭됩니다.

⬇ 설치 및 실행

현재는 GitHub에서 소스를 받아 Python으로 실행하는 방식입니다. 패키징된 .exe 인스톨러는 곧 출시 예정입니다.

🏃 빠른 시작 (권장)

Python을 미리 설치할 필요 없습니다. install.bat이 미설치를 감지하면 자동으로 다운로드·설정합니다(per-user, 관리자 권한 불필요):

# 1. 소스 받기
git clone https://github.com/renstudiodev-TW/david-mouse
cd david-mouse

# 2. 원클릭 설치 (Python + 의존성 자동 처리)
install.bat

# 3. 실행
run.bat

🛠️ 단일 .exe로 패키징

Python 없이도 동작하는 단일 .exe가 필요하다면:

# 1. PyInstaller 설치
pip install pyinstaller

# 2. 빌드 실행
build.bat

# 3. 완성된 exe는 dist\ 폴더 안에
dist\david-mouse.exe
