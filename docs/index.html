HeadMouse Helper 是一款專為頭部控制滑鼠（head-mouse）使用者打造的小工具。 解決最常見的痛點：頭部輕微晃動造成自動點擊誤觸，導致歌曲一直暫停／播放、影片無法好好觀看。 你可以一鍵暫停自動點擊，需要時再恢復。

這個軟體因 David 而生

David 是一位仰賴頭控滑鼠操作電腦的使用者。對他來說，看 YouTube 聽音樂、看影片， 是少數能放鬆、享受、與世界連結的時光。

但他遇到了一個讓人沮喪的問題：他使用的頭控軟體有「自動點擊」功能（停留一定時間就會點下）， 這在多數操作下很方便。可是每當他想單純看 YouTube 時， 頭部的輕微晃動會讓游標不停移動，落在播放區又靜止一下下，結果——影片每隔幾秒就被暫停／恢復一次， 根本沒辦法好好享受。

他的家人（也是我的朋友／個案）找了好幾套商業軟體都解決不了這個問題， 於是我決定動手做一個專屬的工具：一個能「一鍵暫停自動點擊」的視窗， 而且按鈕要夠大、夠明顯，讓頭控也能輕鬆點到。

這就是 HeadMouse Helper 誕生的起點。如果它能幫到 David， 應該也能幫到世界上其他正在面對同樣困擾的人。

🎯 核心功能

整套設計圍繞一個原則：頭控使用者也能不費力地操作。 所有按鈕都是大尺寸、高對比、可以靠停留觸發。

⏯️

一鍵暫停自動點擊

大大的 PAUSE 按鈕，看 YouTube 前先暫停，看完再恢復。不會再被誤觸暫停打斷。

🎚️

可調停留時間

從 0.5 秒到 3 秒可自由調整。每個人的頭部穩定度不同，找到適合自己的節奏。

🖱️

四個動作快捷鍵

左鍵單擊、右鍵單擊、雙擊、暫停／恢復 — 配合 2.5 秒倒數，有時間把游標移到想點的位置。

📐

四角自由停靠

點視窗角落的箭頭，可以把視窗瞬移到螢幕的左上、右上、左下、右下，不擋畫面。

🌐

中英雙語介面

在介面內直接切換中文／English，照顧不同語言的使用者與家屬。

🚀

開機自動啟動

勾選後，每次開機自動跑起來，不用每次手動打開。隨開即用。

📖 怎麼使用？

3 步驟搞定。如果是看 YouTube，記得**先按 PAUSE 鈕暫停自動點擊**再開始看。

1

調整停留時間

用滑桿設定要停留多久才觸發點擊。建議從 1.0 秒開始試。頭部比較穩定的可以設短一點（0.5s），不太穩的設長一點（2s 以上）。

2

看 YouTube 前，先按 PAUSE

把游標移到綠色的「● 自動點擊中」按鈕上，停留 1 秒就會自動點下去，按鈕變紅色「⏸ 已暫停」。這時你就可以安心看影片，不會被誤觸打斷。

3

需要點擊時，用動作鍵

想點什麼東西時，先停留在「左鍵 / 右鍵 / 雙擊」其中一個按鈕上 → 按鈕變黃色倒數 → 在這 2.5 秒內把游標移到目標位置 → 倒數結束自動點下去。

⬇ 安裝與啟動

目前提供從 GitHub 取得原始碼 + Python 執行的方式。 正式打包的 .exe 安裝檔將於近期釋出。

🏃 快速啟動（推薦）

先確認電腦已安裝 Python 3.10+：

# 1. 下載原始碼
git clone https://github.com/renstudio-dev/headmouse-helper
cd headmouse-helper

# 2. 安裝相依套件
install.bat

# 3. 啟動軟體
run.bat

🛠️ 打包成單一 .exe

如果想做成不用裝 Python 也能用的 .exe：

# 1. 安裝 PyInstaller
pip install pyinstaller

# 2. 執行打包
build.bat

# 3. 完成的 exe 在 dist\ 資料夾
dist\HeadMouseHelper.exe
