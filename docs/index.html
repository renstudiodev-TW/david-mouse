💛 為什麼有這個軟體？David 的故事

「如果連最基本的娛樂都被剝奪，生命的重量該如何安放？」

這個軟體因 David 而生

在我的輔具評估生涯裡，曾大衛（頸部脊髓損傷 SCI C-level）的故事，大概是最讓我印象深刻的其中一個。

剛認識大衛時，他的狀況很糟。車禍導致的脊髓損傷讓他失去身體的控制權，生活起居只能全天候仰賴太太。在那個小房間裡，被困住的不只是大衛無法動彈的軀殼，還有太太難以喘息的壓力。身為職能治療師，我知道我的任務不該只是幫他「維持生命徵象」，而是要幫他找回「生活」的感覺。

為了讓他重新與世界連結，我們打算幫他申請一套頭控滑鼠。但在向慈善團體尋求補助時，我們卻碰了個軟釘子。我們隱約感覺到，大眾或機構對於輪椅、電動床這類「傳統輔具」很樂意伸出援手，但一聽到「滑鼠」，就覺得這偏向娛樂消遣，稱不上是生活必需品。

這種社會觀念的落差讓我感觸很深。很多人以為，重度身障者只要能好好活著、能移動就夠了（大衛在初期甚至連脖子都很難移動），卻忽略了「娛樂」與「自主權」往往才是支撐一個人活下去的動力。對大衛來說，用滑鼠玩遊戲、看影片、和外界打字聊天，根本不是什麼奢侈的消遣，那是他唯一能重新掌控自己人生的微小窗口。

幸好，我們並沒有放棄，後來還是幸運地找到了其他資源，順利替大衛買到了頭控滑鼠的硬體設備。

不過，有了硬體之後，真正的挑戰這才在軟體端浮現。

一開始，我們讓他搭配 point-n-click 這套軟體來操作滑鼠。平心而論，它功能強大也很全面，但對非技術背景的家屬來說，進階設定真的太複雜了。大衛的太太光是日常照護就已經耗盡心力，實在很難自己去微調那些層層疊疊的參數。

更讓人氣餒的是，那陣子我們陪著大衛反覆測試、調整了非常多次。但就算好不容易把所有設定都處理好了，軟體依然會發生不受控的自動點擊問題。你可以想像那個畫面：當大衛好不容易點開一部影片，滿心期待想看時，畫面卻因為異常點擊，不斷上演著「播放、暫停、播放、暫停」（play/pause/play/pause）的無限迴圈。

看著他眼裡的期待轉為無奈的挫折感……

「不如我們自己做一套吧！」這個念頭就這樣冒了出來。

我們決定開發一款以「減法設計」為核心的軟體，並用他的名字命名為「david-mouse」。我們把重點全放在 UI/UX 的優化上，只留下最核心、最常用的功能。目標很明確：讓個案和家屬憑直覺就能輕鬆設定，不用老是等專業人員來幫忙。我們甚至把多國語系也加了進去，因為我們私心希望，不只大衛，世界上其他角落的 SCI 病友也能免費下載，找回他們的數位自主權。

「david-mouse」完成後，大衛的生活真的變了。

他現在能靠著頭部細微的動作操作滑鼠，自己上網、找樂子。這不僅讓太太有了喘息的空間，最重要的是——大衛眼裡的光回來了。那個曾經易怒、憂鬱的大衛漸漸消失，因為這顆小小的滑鼠讓他重新嚐到了「掌控感」，他開始有了動機去嘗試更多：他努力練習把話說得更大聲、更清楚；他開始想唱歌；他渴望靠自己的力量去控制更多東西。

這股生命力也推動著我們繼續往前。趁著他這股強烈的動機，我們後來進一步幫他改造了電動輪椅的控制器。現在，大衛已經能自信地自己開著輪椅出門了。

從螢幕上一個小小的游標，到現實世界中自由移動的輪椅。「david-mouse」或許只是一套簡單的軟體，但對大衛來說，那是重啟人生的鑰匙，也是我們想送給全世界脊髓損傷病友的一份禮物。

🎯 核心功能

整套設計圍繞一個原則：頭控使用者也能不費力地操作。 所有按鈕都是大尺寸、高對比、可以靠停留觸發。

⏯️

一鍵暫停自動點擊

大大的 PAUSE 按鈕，看 YouTube 前停留一下暫停，看完再停留一下就恢復。整段過程都不需要實體滑鼠輔助。

🎚️

可調停留時間

從 0.5 秒到 3 秒可自由調整。每個人的頭部穩定度不同，找到適合自己的節奏。

🖱️

四個動作快捷鍵

左鍵單擊、右鍵單擊、雙擊、暫停／恢復 — 配合 2.5 秒倒數，有時間把游標移到想點的位置。

📐

四角自由停靠

點視窗角落的箭頭，可以把視窗瞬移到螢幕的左上、右上、左下、右下，不擋畫面。

🌐

四語系介面

在介面內直接切換 繁體中文 / English / 日本語 / 한국어，照顧不同語言的使用者與家屬。

🚀

開機自動啟動

勾選後，每次開機自動跑起來，不用每次手動打開。隨開即用。

📖 怎麼使用？

3 步驟搞定。如果是看 YouTube，記得**先按 PAUSE 鈕暫停自動點擊**再開始看。

1

調整停留時間

用滑桿設定要停留多久才觸發點擊。建議從 1.0 秒開始試。頭部比較穩定的可以設短一點（0.5s），不太穩的設長一點（2s 以上）。

2

看 YouTube 前，先按 PAUSE

把游標移到綠色的「● 自動點擊中」按鈕上，停留 1 秒就會自動點下去，按鈕變紅色「⏸ 已暫停」。這時你就可以安心看影片，不會被誤觸打斷。

💡 看完想恢復時：再把游標停留在那顆紅色按鈕上即可。暫停狀態下，整個螢幕只有這顆按鈕還能用 dwell 觸發，所以你在看影片時即使頭部晃動到別處，也不會誤觸任何點擊。

3

需要點擊時，用動作鍵

想點什麼東西時，先停留在「左鍵 / 右鍵 / 雙擊」其中一個按鈕上 → 按鈕變黃色倒數 → 在這 2.5 秒內把游標移到目標位置 → 倒數結束自動點下去。

⬇ 安裝與啟動

目前提供從 GitHub 取得原始碼 + Python 執行的方式。 正式打包的 .exe 安裝檔將於近期釋出。

🏃 快速啟動（推薦）

不用先裝 Python——install.bat 偵測到沒裝會自動下載安裝（per-user，免系統管理員權限）：

# 1. 下載原始碼
git clone https://github.com/renstudiodev-TW/david-mouse
cd david-mouse

# 2. 一鍵安裝（自動處理 Python + 相依套件）
install.bat

# 3. 啟動軟體
run.bat

🛠️ 打包成單一 .exe

如果想做成不用裝 Python 也能用的 .exe：

# 1. 安裝 PyInstaller
pip install pyinstaller

# 2. 執行打包
build.bat

# 3. 完成的 exe 在 dist\ 資料夾
dist\david-mouse.exe
